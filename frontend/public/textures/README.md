Credit appears on every immersive page and the About page. The publisher bases
these maps on NASA imagery and elevation data, adjusts colours, and fills some
unmapped regions with plausible fictional terrain. Earth derives from Blue Marble
and other imagery. These are illustrative maps, not live observations or calibrated
scientific products. Lighting, camera perspective and texture mapping are applied
by AegisEarth. The cloud image is used as an opacity map; the ring strip is mapped
radially. Spacecraft geometry is authored in this repository and is illustrative.
