# Releases

The versioned QR3/QR2 wide/deep registry and GET /api/v1/releases are implemented. Discovery
snapshots carry the registry version, retrieval times and SIA receipts. Adapters are explicitly
activated and future formats require validation. Demand-driven 15-minute discovery revalidation
is implemented; scheduled/admin refresh and bulk ingestion remain step 10.
See [discovery](../../../../docs/discovery.md) and docs/sources_and_challenge.md.
