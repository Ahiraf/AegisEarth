# Association (planned)

Optional enhancement; automatic track fitting is deferred from the challenge release. Humans can
inspect many chronological frames without automated association. The viewer must work independently.

Associate per-epoch detections with uncertainty-aware sky-coordinate matching and evidence from residuals.
Classify possible motion, brightness change, artifact or uncertain. Two epochs yield a candidate;
three or more can support a tentative track. No orbital or impact-risk inference is part of this product.
